## About
A console-based Task Management application developed in Python as part of the TNC Group Simplified Python course. The app lets users create, view, edit, and delete tasks, with all data saved persistently to a UTF-8 encoded text file.

## Features
- **List Tasks** — View all tasks with status, priority, and due date
- **Add New Task** — Add tasks with priority level (High/Medium/Low) and optional due date
- **Edit Task** — Modify existing tasks by selecting their number
- **Delete Task** — Remove tasks by selecting their number
- **Toggle Completion** *(Advanced)* — Mark tasks as completed or revert them
- **Sort Tasks** *(Advanced)* — Sort by priority, due date, or completion status

## Getting Started
1. Open `Python_to_do_list.ipynb` in Google Colab
2. Runtime → **Run all**
